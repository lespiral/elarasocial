Política de privacitat d'Elara Social

Última actualització: 22 de novembre de 2026

Aquí t'expliquem quines dades teves recollim quan visites aquesta web o ens contactes, per a què les fem servir i què hi pots fer.

Si t'inscrius a un curs, a l'escola en línia, les dades es tracten segons la política pròpia de l'escola: política de privacitat de l'escola en línia.

En resum

Això és el més important:

  • Pots visitar la web sense donar-nos cap dada personal.
  • No fem servir galetes pròpies ni d'anàlisi. Els formularis de Google, si els fas servir, en tenen de pròpies (vegeu la política de galetes).
  • Si ens escrius o ens truques, fem servir les teves dades només per respondre't.
  • No et demanem informació sobre la teva salut.
  • No venem ni cedim les teves dades a ningú.

Qui és responsable de les dades

Aleix Boronat Monfort, C/ Jaume Casanovas 177, local 2, 08820 El Prat de Llobregat (Barcelona). Correu: lespiral.cat@gmail.com.

Quan només visites la web

La web és allotjada a GitHub Pages (GitHub, Inc.), i el domini es gestiona amb Bluehost. El servidor que allotja la web rep la teva adreça IP i dades tècniques del navegador perquè la pàgina es pugui mostrar. No les fem servir per identificar-te.

Quan ens contactes

Pots escriure'ns per correu, trucar-nos, enviar-nos un WhatsApp o escriure'ns per Instagram. Fem servir el teu nom, el teu correu o telèfon i el que ens expliquis només per respondre la teva consulta. Ho podem fer perquè ens ho demanes (article 6.1.b del Reglament general de protecció de dades, RGPD).

No cal que ens expliquis res sobre la teva salut; si ho fas, només ho fem servir per respondre't. Guardem la conversa el temps necessari per respondre't i, com a màxim, un any a partir del moment en què acabin els cursos, les activitats o les mentories, si no hi ha cap altra relació. Quan fas servir WhatsApp, Instagram o el teu correu, aquests serveis tracten les dades amb les seves pròpies condicions.

Quan omples un formulari

Algunes pàgines porten un formulari per demanar una proposta, inscriure't o fer una reserva. Fem servir les dades que hi escrius per gestionar la teva inscripció o sol·licitud, parlar amb tu d'aquesta activitat i, si ens ho has demanat o hi has donat el consentiment, enviar-te informació d'altres activitats que puguin interessar-te, per correu electrònic o altres mitjans. Les guardem a Google, que ens presta el servei, i no les cedim a ningú més. Pots consultar-les, corregir-les o esborrar-les escrivint a lespiral.cat@gmail.com.

Informació d'activitats

Només t'enviem informació d'activitats si ens ho has demanat o hi has donat el consentiment, que pots retirar quan vulguis responent BAIXA o escrivint-nos.

Qui més hi té accés

Només les empreses dels serveis que fem servir, per prestar-nos el servei: Google (correu i formularis), WhatsApp i Instagram (Meta), GitHub (allotjament de la web), Bluehost (gestió del domini) i, per als cursos, Thinkific. No les venem ni les cedim a ningú. Alguns d'aquests serveis poden tractar dades fora de la Unió Europea, amb les garanties que demana el RGPD.

Els teus drets

Pots demanar-nos veure les teves dades, corregir-les, esborrar-les, limitar-ne o oposar-te'n a l'ús, rebre-les en un format portable i retirar el consentiment. Escriu-nos a lespiral.cat@gmail.com i et respondrem en un màxim d'un mes. Només et demanarem un document d'identitat si tenim dubtes raonables que la petició sigui teva.

Si creus que no hem tractat bé les teves dades, pots reclamar a l'Agència Espanyola de Protecció de Dades (www.aepd.es).

Edat

La web s'adreça a persones adultes.

Canvis en aquesta política

Si la canviem, publicarem la versió nova en aquesta pàgina amb la data d'actualització.
